# Seed plans — import do SmartReps

Gotowe plany do testów katalogu społeczności. Każdy plik zawiera **ćwiczenia + dni + progresję + deload**.

## Jak zaimportować

1. Plany → **Moje** → **Importuj plan JSON**
2. Wybierz jeden z plików poniżej
3. Otwórz szkic → **Aktywuj**
4. Więcej → **Opublikuj w katalogu** (wymaga internetu i podpisu autora)

## Plany

| Plik | Charakter | Dni | Progresja | Deload |
|------|-----------|-----|-----------|--------|
| `fundament-domu-3dni.json` | Początkujący, masa ciała | 3 | +1 powt. / +5 s | co 4. cykl |
| `pompki-solidne-3dni.json` | Średni, fokus pompki | 3 | +1 / +5 s | co 4. cykl |
| `fullbody-ab-hantle.json` | A/B, hantle | 2 | +1 / +2,5 kg | co 4. cykl |
| `upper-lower-4dni.json` | Upper/Lower + supersety | 4 | +1 / +2,5 kg | co 4. cykl |
